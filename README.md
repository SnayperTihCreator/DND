# D&D Interactive Table (Интерактивный стол для настольных игр)

Простой, но функциональный клиент-серверный виртуальный стол для настольных ролевых игр, таких как Dungeons & Dragons. Приложение написано на Python с использованием графической библиотеки PySide6.

Мастер (Ведущий) запускает серверную часть приложения, управляет картами, токенами и туманом войны. Игроки подключаются к Мастеру как клиенты, видят общую карту и могут перемещать свои токены.

## 🌟 Основные возможности

### Для Мастера (GM)
*   **Управление картами:** Создание нескольких карт, загрузка фона для каждой карты, активация карты для игроков и удаление.
*   **Туман войны:** Динамический туман войны, который можно "рисовать" и "стирать" кистью настраиваемого размера.
*   **Настраиваемая сетка:** Возможность наложить на карту сетку, настроить её размер, смещение и цвет.
*   **Управление игроками:** Просмотр списка подключенных игроков, возможность "заморозить" (запретить перемещение) отдельных игроков.
*   **Система заметок:** Создание заметок с текстом и фоном, которые можно отправлять конкретным игрокам.
*   **Панель токенов:** Область для хранения токенов NPC и монстров.
*   **Интегрированный справочник:** Встроенный браузер с быстрым доступом к онлайн-справочнику по правилам D&D 5e.
*   **Управление доступом:** Возможность "открыть" или "закрыть" стол для подключения новых игроков.

### Для Игрока
*   **Простое подключение:** Достаточно ввести IP-адрес и порт Мастера.
*   **Создание персонажа:** Простой экран для ввода имени персонажа и выбора класса.
*   **Взаимодействие с картой:** Просмотр активной карты, сетки и перемещение своего токена.
*   **Получение заметок:** Всплывающие окна с заметками от Мастера, которые сохраняются в личном архиве.
*   **Синхронизация:** Все изменения на столе Мастера (смена карты, туман войны, сетка) мгновенно отображаются у игрока.
*   **Интегрированные листы:** Быстрый доступ к онлайн-листу персонажа и справочнику по своему классу.

## 🛠️ Как это работает (Технический обзор)

Приложение использует **клиент-серверную архитектуру**:
1.  **Мастер (Сервер):** Запускает WebSocket сервер, который принимает подключения от игроков. Также он запускает локальный HTTP-сервер для раздачи файлов (фоны карт, изображения токенов). Это позволяет не передавать тяжелые файлы по основному каналу связи.
2.  **Игрок (Клиент):** Подключается к WebSocket серверу Мастера. Когда требуется загрузить файл (например, фон новой карты), клиент получает URL от Мастера и скачивает его напрямую с HTTP-сервера Мастера.

Вся логика построена на асинхронном взаимодействии с помощью `asyncio`, что интегрировано в цикл событий Qt благодаря библиотеке `qasync`.

### Основные технологии
*   **Язык:** Python 3
*   **GUI:** PySide6 (Qt for Python)
*   **Асинхронность:** `asyncio` + `qasync`
*   **Сеть:** `websockets` для обмена сообщениями, `aiohttp` (внутри `AsyncServerBridge`) для раздачи файлов.
*   **Логирование:** стандартный модуль `logging` с ротацией файлов

## 🚀 Начало работы

Это приложение не требует установки. Просто скачайте, настройте сеть и играйте!

1.  **Скачайте последнюю версию.**
    Перейдите в раздел [**Releases**](https://github.com/SnayperTihCreator/DND/releases) и скачайте архив с приложением.

2.  **Распакуйте архив.**
    Извлеките файлы в любую удобную папку на вашем компьютере.

3.  **Настройте виртуальную сеть (обязательно для игры по интернету).**
    Приложение работает в локальной сети. Чтобы играть с друзьями, которые не находятся с вами в одной Wi-Fi сети, всем участникам (и Мастеру, и игрокам) нужно установить и запустить программу для создания виртуальной локальной сети.
    *   **Radmin VPN** (рекомендуется, бесплатно и просто для Windows)
    *   **TailScale** (рекомендуется, бесплатно и просто для кроссплатформы)
    *   **Hamachi**

    Убедитесь, что все вы находитесь **в одной и той же сети** внутри Radmin VPN (или аналога) и что программа запущена.

4.  **Запустите приложение.**
    Найдите в папке исполняемый файл (например, `Dnd Table Runner.exe`) и запустите его. Вас встретит окно-лаунчер.

## 🎮 Как использовать

Лаунчер — это ваш центр управления для создания стола или подключения к игре.

### Для Игроков (Как подключиться к игре)

Подключиться к столу Мастера очень просто.

1.  Запустите приложение. Откроется вкладка **"Найти игру"**.
2.  Приложение **автоматически просканирует** вашу сеть (LAN/VPN) и покажет список доступных столов.
3.  **Простой способ:** Просто **дважды щёлкните** по нужному столу в списке.
4.  **Резервный способ:** Если стол не появился в списке, попросите у Мастера его IP-адрес и порт, введите их в поля "Подключиться напрямую" и нажмите кнопку.
5.  Перед подключением введите ваш никнейм/имя профиля в поле внизу.
6.  После подключения откроется окно создания персонажа (выбор имени, класса). Создайте его, и вы в игре!

> **Важно:** Если список серверов пуст, убедитесь, что вы и Мастер находитесь в одной сети Radmin VPN, и нажмите кнопку **"Обновить список"**.

### Для Мастера (Как создать стол)

1.  Запустите приложение и перейдите на вкладку **"Создать стол"**.
2.  Введите ваш никнейм (например, "DungeonMaster").
3.  Нажмите кнопку **"Создать стол"**. Лаунчер закроется, и откроется основной интерфейс Мастера.
4.  В верхней панели инструментов вы увидите ваш **IP-адрес** (из виртуальной сети) и **порт** сервера.
5.  **Сообщите эти IP-адрес и порт игрокам**, которые не могут найти ваш стол автоматически.
6.  Нажмите кнопку **"🔴 Стол закрыт"**, чтобы она сменилась на **"🟢 Стол открыт"**. Теперь игроки могут подключаться.
7.  Используйте панель инструментов для создания карты (`Создать карту`), загрузки фона (`Загрузить фон`) и её активации для игроков (`Активировать карту`).

### Для разработчиков (Сборка и запуск из исходного кода)

Проект использует `uv` — современный и быстрый менеджер пакетов и виртуальных окружений для Python.

1.  **Установите uv:**
    Следуйте [официальной инструкции по установке uv](https://github.com/astral-sh/uv#installation).

2.  **Склонируйте репозиторий:**
    ```bash
    git clone [ссылка_на_ваш_репозиторий]
    cd [название_папки_проекта]
    ```
3.  **Создайте виртуальное окружение и установите зависимости с помощью `uv`:**
    ```bash
    uv sync
    ```
4.  **Запустите приложение:**
    ```bash
    uv run src/main.py
    ```

Сборка исполняемого файла также производится с помощью `PyInstaller`, который можно установить и запустить через `uv`.
